## 1. 测试环境准备

| 项 | 说明 |
|---|---|
| 后端 | 项目根目录运行 `./mvnw spring-boot:run`，端口 8080（需先建库，账号密码在 `application-local.yml`） |

### T10 异常与边界场景

| 场景 | 预期结果 |
|---|---|
| 未登录直接访问接口 | 401，统一提示"未登录或会话已过期" |
| 请求体缺必填字段（如注册不填电话） | 400，提示具体字段错误 |
| 请求体非法 JSON / 编码错误 | 400"请求体格式错误" |
| 下单时菜单项不属于当前菜单 | 400"菜单项不属于当前使用中菜单" |
| 下单时无使用中菜单 | 400"当前没有使用中的菜单" |
| 食谱中删除已被菜单引用的菜品 | 删除成功，菜单中该菜照常显示（快照解耦） |
| 报表查询月份格式错误（如 2026/09） | 400"月份格式非法，应为 yyyy-MM" |
| 服务端重启后前端刷新 | 原会话失效需重新登录（Session 内存存储特性） |

## 4. 演示建议流程（答辩 5 分钟版）

1. 经理登录 → 创建食谱菜品（2 个）→ 创建菜单并启用（T3/T4）
2. 员工登录 → 点餐下单（T5.1-T5.3）→ 展示"每日一单"拦截（T5.4）
3. 经理改菜单价格 → 员工看旧订单价格不变（T5.6，快照亮点）
4. 厨房主管看总括订单（T6.4）→ 配餐员看批量订单（T6.5，打印预览）
5. 经理看月度销售统计（T7.1）→ 员工看个人消费统计（T7.4）
6. 演示权限拦截：员工访问用户管理 → 403（T9）
7. 数据库展示：order_items 快照价格与 menu_items 当前价格对比
